          02 — AGENTIC AI & VULNERABILITY FUZZING

          MUTAGEN AI FUZZER

          AUTONOMOUS 5-PHASE FUZZER & AUTO-PATCHER STACK: PYTHON // GEMINI · CLAUDE · GPT · OLLAMA // GHIDRA

          Mutagen is an agentic AI fuzzer built in Python that reads source code (or a compiled binary via Ghidra decompilation), finds vulnerabilities, generates exploits, patches the bugs, and proves the fix works — fully autonomously. Rather than the random mutation traditional fuzzers rely on, Mutagen uses an LLM (Gemini, Claude, GPT, or a local Ollama model) to reason about the code, target high-entropy edge cases, and learn from each failed attempt before retrying.

          Verified run (my own AWS lab — Ubuntu, Docker + AddressSanitizer sandbox) on targets/01_buffer_overflow.c: Mutagen reproduced a real stack-buffer-overflow — ASan caught a WRITE of size 65 into a 32-byte buffer via strcpy, a 100% crash rate on the generated payload — auto-generated a working Python exploit, auto-patched it (strcpy → snprintf(buf, sizeof(buf), …)), and verified the fix — self-healing refined the patch until it compiled and the exploit no longer crashed the target (Verification: VERIFIED SECURE). The harness itself is the project and is model-agnostic (Gemini / Claude / GPT / local).
