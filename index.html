02 — AGENTIC AI & VULNERABILITY FUZZING

MUTAGEN AI FUZZER

AUTONOMOUS 5-PHASE FUZZER & AUTO-PATCHER STACK: PYTHON // GEMINI · CLAUDE · GPT · OLLAMA // GHIDRA

Mutagen is an agentic AI fuzzer built in Python that reads source code (or a compiled binary via Ghidra decompilation), finds vulnerabilities, generates exploits, patches the bugs, and proves the fix works — fully autonomously. Rather than the random mutation traditional fuzzers rely on, Mutagen uses an LLM (Gemini, Claude, GPT, or a local Ollama model) to reason about the code, target high-entropy edge cases, and learn from each failed attempt before retrying.

01 // ANALYZE

The LLM reads the target source (or decompiles a binary via Ghidra) and identifies candidate vulnerabilities and edge cases.

02 // COMPILE

Compiles the target with a crash handler injected so failures can be captured and attributed precisely.

03 // FUZZ

Executes AI-generated payloads against the target; the agent learns from failed attempts and retries with adjusted inputs.

04 // PATCH & EXPLOIT

Once a crash is confirmed, Mutagen drafts a secure C patch and a Python proof-of-concept exploit.

05 // VERIFY

Re-runs the fuzzing campaign against the patched target to confirm the vulnerability is actually eliminated.
